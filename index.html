Três trilhas pelo vale

Cada trilha é um caminho de lições. Você escolhe por onde começar.

  1. Python na floresta

    Faça o computador falar, contar e tomar decisões. E conserte as máquinas quebradas do Bit.

    print("Olá, mundo!")

  2. HTML na vila

    Monte páginas de verdade com títulos, listas, imagens e links, peça por peça.

    <h1>Minha página</h1>

  3. CSS no jardim

    Pinte, arrume e enfeite suas páginas com cores, espaços e cantos redondos.

    h1 { color: orange; }

Como é uma aula

  • O Bit explica na lousa. Uma ideia de cada vez, com exemplos curtinhos.
  • Você pratica na hora. Escolhe respostas, completa código, conserta máquinas.
  • A bola de neve cresce. Cada acerto rola a bola até a próxima bandeira. No fim, ela vira um boneco de neve.
